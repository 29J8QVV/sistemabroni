Свободные аудитории и лаборатории

IT-Лаборатория

30 современных рабочих мест с предустановленным софтом для программирования, сетевого администрирования и 3D-моделирования.

Доступно для брони

Медиастудия

Пространство со звукоизоляцией для записи видеолекций, вебинаров и подкастов. Оборудовано хромакеем и профессиональным светом.

Доступно для брони

Робоцентр

Класс для практических занятий по робототехнике, микроэлектронике и схемотехнике. Есть паяльные станции и отладочные платы.

Доступно для брони

Смарт-Лекторий

Зал для лекций на 80 мест с большой интерактивной панелью, беспроводными микрофонами и системой климат-контроля.

Доступно для брони

Техно-Коворкинг

Зона свободной коллективной работы студентов и преподавателей. Маркерные стены, флипчарты, ноутбуки и быстрый Wi-Fi.

Доступно для брони

Цифровая лаборатория

Пространство для индивидуальной и проектной работы студентов. Современные компьютеры, настенные мониторы и быстрый Wi-Fi.

Доступно для брони

Переговорная комната

Уютный кабинет для совещаний, защиты проектов и работы в малых группах. Большой экран для презентаций, флипчарт и ВКС-система.

Доступно для брони

VR-пространство

Аудитория для работы с виртуальной и дополненной реальностью. Шлемы VR, мощные графические станции и трекинг-система.

Доступно для брони

Актовый зал

Просторный зал для конференций, хакатонов и крупных мероприятий. Сцена, проектор, профессиональный звук и радиомикрофоны.

Доступно для брони

Инженерная мастерская

Лаборатория для прототипирования и сборки устройств. 3D-принтеры, паяльные станции, измерительные приборы и наборы инструментов.

Доступно для брони

Центр симуляций

Специализированный кабинет с тренажерами и симуляторами для отработки профессиональных практических навыков.

Доступно для брони

Переносное учебное оборудование

Мобильный проектор (Комплект)

Переносной проектор, кабели питания, HDMI-провод, пульт ДУ и перекатной экран.

Ноутбук преподавателя

В наличии
